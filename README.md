# Adarsh Raj - Personal Website

Welcome to my personal website repository! This repository hosts the code for my personal website, showcasing my skills and providing information about me.

## Preview

[View Live](https://html-site-adarsh.vercel.app/)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design using CSS media queries.
- Uses Google Fonts for typography.
- Contact form integration for direct communication.

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. Open `index.html` in your web browser to view the website locally.

## Usage

Explore different sections of the website:
- **Home**: Introduction and basic information.
- **Skills**: Details about my skills in Computer Science and Engineering.
- **Contact**: Get in touch with me via email.
